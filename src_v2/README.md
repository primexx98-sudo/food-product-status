# 일반식품 분류 로직 v2 (실험용, 별도 버전)

2026-08-28 시작. 기존 `src/category_mapper.py`의 일반식품 분류 로직(`categorize_general_food`,
`_GENERAL_MAP` 등)을 카테고리별로 인터뷰 형식으로 하나씩 처음부터 재검토·재구축하는 실험용 버전.

## 목적

기존 로직은 6월부터 카테고리별 개별 인터뷰·버그 수정을 누적해온 결과물이라, 카테고리마다 만들어진
시점·기준이 달라 일관성이 떨어질 수 있음. 카테고리 17종(기타 제외 16종)을 하나씩 처음부터 다시
설계해서, 기존 로직과 정확도를 비교한 뒤 더 정확하면 교체한다.

## 원칙

- **카테고리 구성 자체는 유지** — `GENERAL_CAT_LIST` 17종(피부/에너지/단백질/효소/항산화/혈행개선/
  관절/다이어트/면역/수면/피로개선/프로바이오틱스/구강/여성건강/남성건강/모발/혈당/기타)은 그대로.
  바뀌는 건 각 카테고리를 판별하는 키워드/규칙 로직뿐.
- **기존 `src/category_mapper.py`는 건드리지 않음** — 실서비스는 그대로 기존 로직으로 계속 운영.
- **판단은 사용자 샘플 검수로** — 카테고리별로 신구 로직 분류 결과 차이(diff)를 샘플로 뽑아
  사용자에게 보여주고, 어느 쪽이 더 정확한지 직접 판단받는다. 정량 지표(v2 참고 데이터 등)는
  참고용일 뿐 채택 기준이 아님.
- **인터뷰 진행 방식**: 카테고리 하나씩, 아래 순서로 딥다이브
  1. 이 카테고리가 잡아야 할 "진짜" 제품이 뭔지 사용자와 정의(트렌드 성분/브랜딩 기준 등)
  2. 현재 수집 데이터에서 관련 후보 샘플을 뽑아 실제로 보여주며 포함/제외 기준 확인
  3. 키워드/규칙을 `category_mapper_v2.py`에 작성
  4. 기존 로직과 비교 결과를 diff로 뽑아 검수받고 확정 또는 재수정
