# 품목신고및보고현황

식품안전나라 OPEN-API를 활용하여 건강기능식품·일반식품 품목 신고/보고 현황을 수집하고,
기능성 카테고리별로 분류하여 월별 엑셀 파일로 저장하는 자동화 프로젝트입니다.

---

## 실행 방법

```powershell
# PowerShell — 매월 말일 또는 필요 시 실행
$env:FOOD_API_KEY = "인증키"
python src/main.py
```

출력: `output/YYYY-MM_품목신고보고현황.xlsx`

> **PRMS_DT 필터는 누적형(≥)** 으로 동작 — 반드시 해당 월 말에 수집해야 정확한 월별 데이터를 얻을 수 있음
> **GitHub Actions**: 한국 정부 API의 해외 IP 차단으로 실제 동작 불가. 로컬 수동 실행이 유일한 정상 경로.

---

## 수집 대상

| 구분 | 서비스 코드 | 월 수집 건수 |
|------|------------|------------|
| 건강기능식품 | C003 | 500 ~ 700건 |
| 일반식품 | C002 (제품형태 필터 후) | 1,000 ~ 2,000건 |

## 카테고리 분류

- 건강기능식품: 주된기능성 + 품목명 + 원재료 3필드 조합, 23종 카테고리
- 일반식품: 품목명 우선 → 원재료명 보조, 17종 카테고리 + 기타
- 오분류 발견 시 → `src/category_mapper.py`의 `_HEALTH_MAP` / `_GENERAL_MAP` 키워드 수정 후 재실행

분류 로직 상세, 특수 규칙, 현재 카테고리 목록, 기타 비율 등은 [설계서.md](설계서.md) 참고.
