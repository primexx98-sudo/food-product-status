# 품목신고및보고현황

식품안전나라 OPEN-API를 활용하여 건강기능식품·일반식품 품목 신고/보고 현황을 매일 자동 수집하고, 기능성 카테고리별로 분류하여 월별 엑셀 파일로 저장하는 자동화 프로젝트입니다.

---

## 주요 기능

- 건강기능식품 품목제조신고 현황 수집 및 기능성별 카테고리 자동 분류
- 일반식품 품목제조보고 현황 수집 및 기능성별 카테고리 자동 분류
- 월별 엑셀 파일 생성 (당월 데이터 매일 덮어쓰기)
- GitHub Actions를 통한 매일 자동 실행

---

## 엑셀 구조

| 시트 | 내용 |
|------|------|
| 건강기능식품 | 당월 신고 현황 + 카테고리 |
| 일반식품 | 당월 보고 현황 + 카테고리 |
| DASHBOARD | 기능성별 월별 집계 (연도 기준 A1 셀 입력) |

파일명: `YYYY-MM_품목신고보고현황.xlsx`

---

## 카테고리 분류

**건강기능식품** (주된기능성 키워드 기반)
> 멀티팩 / 비타민 / 다이어트 / 이너뷰티 / 장 / 눈 / 두뇌 / 뼈건강 / 관절 / 간 / 위 / 피로개선 / 수면 / 항산화 / 혈행개선 / 혈당 / 여성건강 / 남성건강 / 프로바이오틱스 / 오메가3 / 홍삼 / 단백질

**일반식품** (품목명 우선, 원재료명 보조)
> 피부 / 에너지 / 단백질 / 효소 / 관절 / 다이어트 / 면역 / 수면 / 피로개선 / 프로바이오틱스 / 구강 / 여성건강 / 남성건강 / 모발 / 혈당 / 기타

## 실행 방법

### 자동 실행
GitHub Actions가 매일 오전 10시(KST) 자동 실행합니다.

### 수동 실행
```bash
pip install -r requirements.txt
python src/main.py
```
