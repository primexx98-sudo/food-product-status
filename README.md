# 품목신고및보고현황

식품안전나라 OPEN-API를 활용하여 건강기능식품·일반식품 품목 신고/보고 현황을 수집하고,
기능성 카테고리별로 분류하여 월별 엑셀 파일로 저장하는 자동화 프로젝트입니다.

---

## 실행 방법

> **GitHub Actions 미사용** — 한국 정부 API가 해외 IP를 차단하므로 로컬에서만 실행 가능

```powershell
# PowerShell — 매월 말일 또는 필요 시 실행
$env:FOOD_API_KEY = "인증키"
python src/main.py
```

출력: `output/YYYY-MM_품목신고보고현황.xlsx`

---

## 수집 대상

| 구분 | 서비스 코드 | 월 수집 건수 |
|------|------------|------------|
| 건강기능식품 | C003 | 500 ~ 700건 |
| 일반식품 | C002 (제품형태 필터 후) | 1,000 ~ 2,000건 |

## 카테고리 분류

### 건강기능식품 (주된기능성 + 품목명 + 원재료 3필드 조합)
`멀티팩 / 비타민 / 다이어트 / 이너뷰티 / 장 / 눈 / 두뇌 / 뼈건강 / 관절 / 간 / 위 / 피로개선 / 수면 / 항산화 / 혈행개선 / 혈당 / 여성건강 / 남성건강 / 프로바이오틱스 / 오메가3 / 홍삼 / 단백질`

신뢰도: 프로바이오틱스(97%) · 간(89%) · 오메가3(86%) 높음 / 비타민·홍삼·혈행개선 낮음(<60%)

### 일반식품 (품목명 우선 → 원재료명 보조)
`피부 / 에너지 / 단백질 / 효소 / 관절 / 다이어트 / 면역 / 수면 / 피로개선 / 프로바이오틱스 / 구강 / 여성건강 / 남성건강 / 모발 / 혈당 / 기타`

#### 특수 규칙
| 조건 | 카테고리 |
|------|---------|
| 품목명·원재료에 `맥주효모` 또는 원재료에 `효모`+`비오틴` 동시 | 모발 |
| 품목명에 `이노시톨` / `콜린미오` / `콜린미오이노시톨` / `미오이노시톨콜린` | 여성건강 |
| 품목명에 `파우더` | 기타 |
| 원재료에 `효소처리스테비아` | 효소 키워드 무시 (→ 기타) |
| 원재료에 `피로인산제일철` | 피로 키워드 무시 |

오분류 발견 시 → `src/category_mapper.py`의 `_HEALTH_MAP` / `_GENERAL_MAP` 키워드 수정 후 재실행

## 주의사항

**PRMS_DT 필터는 누적형(≥)** 으로 동작합니다.
- `PRMS_DT=202606` → 6월 이후 데이터만 반환 (현재 = 6월뿐)
- `PRMS_DT=202601` → 1~6월 전체 누적 반환 (과거 데이터 재수집 시 부정확)
- **반드시 해당 월 말에 수집해야 정확한 월별 데이터를 얻을 수 있음**
