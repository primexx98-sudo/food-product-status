# 품목신고및보고현황

식품안전나라 OPEN-API를 활용하여 건강기능식품·일반식품 품목 신고/보고 현황을 수집하고,
기능성 카테고리별로 분류하여 월별 엑셀 파일로 저장하는 자동화 프로젝트입니다.

---

## 실행 방법

```powershell
# PowerShell — 매월 말일 또는 필요 시 실행
$env:FOOD_API_KEY = "인증키"
python src/main.py
```

출력: `output/YYYY-MM_품목신고보고현황.xlsx`

> **GitHub Actions**: `.github/workflows/daily_crawl.yml`이 매일 10:00 KST에 실행됩니다.
> 한국 정부 API가 해외 IP를 차단할 경우 타임아웃 후 exit 0(스킵)으로 처리 — 워크플로 실패 없음.
> 정확한 월 데이터는 **월말 로컬 수동 실행**으로 수집 권장.

---

## 수집 대상

| 구분 | 서비스 코드 | 월 수집 건수 |
|------|------------|------------|
| 건강기능식품 | C003 | 500 ~ 700건 |
| 일반식품 | C002 (제품형태 필터 후) | 1,500 ~ 2,000건 |

### 일반식품 포함 제품형태 (v2 기준 10종)
`기타가공품 / 과.채가공품 / 액상차 / 당류가공품 / 고형차 / 캔디류 / 과.채주스 / 효소식품 / 발효식초 / 올리브유`

### 일반식품 자동 제외 대상
- 품목명 suffix 기준: `청 / 소스 / 양념 / 드레싱 / 나물`
- 품목명 포함 기준 (B2B 원료·반제품·시즈닝류, 코드가 붙은 형태 다수라 suffix 매칭 불가): `시즈닝 / 씨즈닝 / 베이스 / 반제품 / 조미액 / 조미분`
  - `그레인`은 제외하지 않음 — "파라다이스그레인" 등 실제 효소식품 브랜드 존재

## 카테고리 분류

### 건강기능식품 (주된기능성 + 품목명 + 원재료 3필드 조합)

```
멀티팩 / 면역 / 비타민 / 다이어트 / 이너뷰티 / 장 / 눈 / 두뇌
뼈건강 / 관절 / 간 / 위 / 피로개선 / 수면 / 항산화 / 혈행개선
혈당 / 여성건강 / 남성건강 / 프로바이오틱스 / 오메가3 / 홍삼 / 단백질
```

**분류 로직 우선순위**
1. 품목명에 멀티팩 키워드 or 기능성 원료 10개 이상 → 멀티팩
2. `[원료명]` 괄호 항목이 모두 비타민/미네랄 → 비타민 (뼈건강 텍스트 있으면 뼈건강)
3. `[원료명]` 괄호 추출 → `_HEALTH_MAP` 우선순위 매칭
4. 기능성 전체 텍스트 매칭 (서술형 포함: "에너지 이용에 필요" 등)
5. 품목명 → 원재료 순 보조 매칭

**6월 기타: 0건** (카테고리 분류 완전 커버)

### 일반식품 (품목명 우선 → 원재료명 보조)

```
피부 / 에너지 / 단백질 / 효소 / 항산화 / 혈행개선 / 관절 / 다이어트
면역 / 수면 / 피로개선 / 프로바이오틱스 / 구강 / 여성건강 / 남성건강
모발 / 혈당 / 기타
```

**특수 규칙**
| 조건 | 결과 |
|------|------|
| 품목명·원재료에 `맥주효모` 또는 원재료에 `효모`+`비오틴` | 모발 |
| 품목명에 `이노시톨` / `콜린미오이노시톨` 계열 | 여성건강 |
| 품목명에 `파우더` | 기타 |
| 품목명 suffix가 `청` / `소스` / `시즈닝` / `양념` / `드레싱` / `나물` | 수집 제외 |
| 원재료에 `효소처리스테비아` / `피로인산제일철` | 오분류 방지 마스킹 |

**6월 기타: 67.7%** (건강기능과 무관한 일반 식품 포함)
**v2 참고데이터(9,033건) 재검증: 72.0% → 69.2%** (2026-07-01 B2B 제외 + 키워드 보강 후, 오미자→항산화·애사비→다이어트·도라지·맥문동→면역 추가)

오분류 발견 시 → `src/category_mapper.py`의 `_HEALTH_MAP` / `_GENERAL_MAP` 키워드 수정 후 재실행

## 주의사항

**PRMS_DT 필터는 누적형(≥)** 으로 동작합니다.
- `PRMS_DT=202606` → 6월 이후 데이터만 반환
- **반드시 해당 월 말에 수집해야 정확한 월별 데이터를 얻을 수 있음**
